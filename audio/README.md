# Room Cable

Минимальный виртуальный аудиокабель для macOS 13+ на C++20. Одно устройство **Room Cable**
с выходом и входом: всё, что приложения воспроизводят в выход, появляется на входе.
Маршрут для Room: Browser Source в OBS → мониторинг OBS → Room Cable → микрофон Zoom.
Устанавливать на Mac с **принимающим OBS**.

- Стерео, 48 000 Гц, interleaved Float32 PCM. Кодеков и сжатия нет.
- Собственная задержка кольцевого буфера — 512 сэмплов, около 10,7 мс. Задержки OBS,
  Core Audio, сети и приложения звонков добавляются отдельно.
- Общий поток можно читать из нескольких приложений. Выходы приложений смешивает Core Audio.
- Формат фиксированный; виртуальных регуляторов громкости и mute нет. Громкость регулируется в OBS.
- HAL-плагин, без kext, DriverKit, фонового сервера или Node-аддона.

## Сборка и установка

Нужны только Apple Command Line Tools (`xcode-select --install`, если их ещё нет).
Ни Xcode-проект, ни Homebrew, ни npm для кабеля не нужны.

```sh
cd audio
make
make check
sudo ./install.sh --restart-audio
```

`make` собирает universal bundle для **arm64 + x86_64**, затем подписывает его локальной
ad-hoc подписью. Платный сертификат для этой локальной сборки не используется. Артефакт:
`build/RoomCable.driver`. Это не нотарифицированный установщик для распространения через интернет.

Установка копирует только этот bundle в `/Library/Audio/Plug-Ins/HAL/RoomCable.driver`.
Повторная установка сохраняет предыдущую версию рядом с суффиксом `.backup-…`.
`--restart-audio` перезапускает Core Audio: текущий звук и звонки на время прервутся.
Можно не передавать флаг и позже перезагрузить Mac. Системные устройства по умолчанию
скрипт не меняет.

## OBS → Zoom

1. В OBS у Browser Source включить **Control audio via OBS**.
2. **Settings → Audio → Advanced → Monitoring Device → Room Cable**.
3. У нужного источника в **Advanced Audio Properties → Audio Monitoring** выбрать
   **Monitor Only (mute output)**. Для параллельной записи/стриминга — **Monitor and Output**.
4. В Zoom выбрать **Microphone → Room Cable**. Выход Zoom оставить на обычных колонках/наушниках.

Не отправляй выход Zoom обратно в Room Cable: собеседник услышит сам себя.
Видео отдельно поступает через OBS Virtual Camera.

## Удаление

```sh
sudo ./uninstall.sh --restart-audio
```

Удаляется только установленный Room Cable, с проверкой bundle identifier. Сохранённые
резервные версии не удаляются автоматически.

## Устройство и проверки

`RoomCable.cpp` реализует `AudioServerPlugInDriverInterface`: обнаружение устройства,
свойства, постоянный формат, часы, `WriteMix` и `ReadInput`. Большая часть файла — контракт Core Audio.
`Loopback.hpp` хранит PCM в кольцевом буфере по абсолютным номерам сэмплов. Чтение возвращает
тишину для отсутствующих или устаревших данных. В IO нет блокирующих mutex, выделения памяти,
вызовов файловой системы и логирования. Блокировки используются только при запуске/остановке.

`make check` загружает собранный `.driver` через CFPlugIn в отдельном процессе с тестовым host.
Проверяются регистрация, свойства, неизменность PCM, разные размеры блоков, переход через
границу буфера, повторное чтение, тишина, отключение потоков, несколько IO-клиентов, остановка
и запуск, частота часов, конкурентное чтение и перезапись. Системный HAL при этом не меняется.
Это проверка плагина, а не подтверждение совместимости с установленными OBS/Zoom: её нужно
проводить после установки на принимающий Mac.

API: [Audio Server Driver Plug-in](https://developer.apple.com/documentation/coreaudio/creating-an-audio-server-driver-plug-in).
